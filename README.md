# Подмена

Локальное приложение для обратимой подмены заданных значений в Excel.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

Загрузите книгу .xlsx и добавьте пары в матрицу, например «Анна Петрова → КЛИЕНТ_001». Скачайте подменённую книгу. Для восстановления загрузите обработанный файл и укажите те же пары в режиме «Восстановить».

Поиск идёт по текстовым ячейкам с учётом регистра. Числа и даты копируются как значения. Результат — новая книга со значениями ячеек видимых листов. Формулы, оформление, исходные названия листов, комментарии, скрытые листы и вложенные объекты исключаются. Перед передачей проверьте значения в полученной книге: приложение заменяет только совпадения из вашей матрицы. Матрица хранится в текущем сеансе. Для повторного использования сохраните её отдельно у себя.
