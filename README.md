# Подмена

«Подмена» — командное веб-приложение для обратимой замены конфиденциальных значений перед передачей документов на обработку. В Excel оно подменяет текст и числа в выбранных областях, а для остальных поддерживаемых форматов работает с извлечённым текстом. Приложение показывает предпросмотр, сохраняет матрицы подмены и их версии в личном кабинете и восстанавливает исходные значения по выбранной версии. История связывает операции с использованными версиями матриц.

## Запуск

Нужны Docker с Compose v2 и Python 3 для генерации секретов. На сервере укажите домен приложения в `.env` и направьте на сервер DNS. Для публичного сертификата Caddy использует порты 80 и 443. Для разработки можно оставить `APP_DOMAIN=localhost`; браузеру потребуется доверие к локальному удостоверяющему центру Caddy.

```bash
cp .env.example .env
mkdir -m 700 .secrets
python3 - <<'PY'
from pathlib import Path
from secrets import token_urlsafe

for name in ("db_password", "db_admin_password", "matrix_key"):
    path = Path(".secrets") / name
    with path.open("x") as stream:
        stream.write(token_urlsafe(32) + "=\n" if name == "matrix_key" else token_urlsafe(36) + "\n")
    path.chmod(0o444)
PY
docker compose up -d --build --wait
docker compose exec app python -m server.accounts create alice
```

Секреты защищены закрытым каталогом на хосте. Режим файлов позволяет читать смонтированные секреты непривилегированным процессам контейнеров, где файлы доступны только назначенным сервисам. Ключ матриц один на развёртывание. После запуска сохраните его резервную копию в отдельном защищённом месте.

Откройте `https://<домен>`. Доступ к PostgreSQL из внешней сети отсутствует. Миграции выполняет контейнер `migrate` перед стартом приложения. Для локального сертификата выгрузите `/data/caddy/pki/authorities/local/root.crt` из контейнера `proxy` и добавьте сертификат в хранилище доверия на своём устройстве.

Для локального HTTP запускайте тот же проект с дополнительной конфигурацией. Она публикует только порт 80 на адресе `127.0.0.1` и использует локальную сессию по HTTP. Для этого варианта нужен Compose 2.24.4 или новее.

```bash
HTTP_PORT=80 docker compose -f compose.yaml -f compose.http.yaml up -d --build --wait
```

Откройте `http://localhost`. Уже созданные учётки и матрицы находятся в той же базе. Войдите снова после переключения. На Linux можно записать `COMPOSE_FILE=compose.yaml:compose.http.yaml` в `.env`, чтобы обычные команды `docker compose` использовали этот режим.

Для управления учётками используйте ту же команду с действиями `reset`, `block` или `unblock`. Сброс пароля и блокировка завершают серверные сессии. Логины состоят из латинских букв, цифр и символов `. _ @ + -`.

## Как работать

1. Выберите «Подменить» и откройте книгу. Нажатие на заголовок выделяет строку или столбец. Перетаскивание выделяет прямоугольник. Ctrl или Cmd добавляет область. Для точного выделения введите адрес в формате `C2:C8`, `C:C` или `2:5`. С клавиатуры используйте стрелки и Shift для диапазона, Enter для выбора ячейки.
2. Выберите или назовите матрицу, введите пары или заполните их из выделения. Предпросмотр показывает примеры изменений, конфликты и предупреждения. Подтвердите предупреждения после проверки книги и скачайте Excel. После скачивания версия матрицы и метка операции доступны в истории.
3. Для ответа ИИ откройте «Восстановить». Выберите сохранённую версию и вставьте текст либо загрузите ответный Excel. По умолчанию Excel обрабатывается на всех видимых листах. Можно выбрать конкретную область.
4. В «Матрицах» можно редактировать, архивировать, выгружать версии в JSON и импортировать их как новые матрицы. Храните JSON в защищённом месте. В них есть исходные значения.

В режиме «Текст и файлы» можно вставить текст либо открыть TXT, Markdown, CSV, TSV, LOG, JSON, DOCX или PDF. Выделите фрагмент и нажмите «Добавить выделение» или Ctrl/⌘ + Enter. Приложение добавит пару с уникальным кодом в матрицу. Подмена применяется ко всем точным совпадениям. Текстовый черновик и предпросмотр сохраняются при переходе между разделами в открытой вкладке. Проверьте предпросмотр, сохраните матрицу и скопируйте результат либо скачайте его как TXT. Восстановление из текста поддерживает те же форматы.

Кнопка «Найти фрагменты» предлагает адреса электронной почты, телефоны, текст внутри кавычек и слова с заглавной буквы в середине предложения. Проверьте контекст и нажмите «Добавить» для нужных фрагментов. Для текста в кавычках в матрицу попадает содержимое, а сами кавычки сохраняются при подмене.

Из Word извлекается основной текст, включая текст в таблицах, а из PDF — текстовый слой. Выгрузка идёт в TXT. Лимиты импорта составляют 10 МБ и 250 000 символов; для PDF действует ограничение в 120 страниц. Текстовые файлы должны быть в UTF-8 или UTF-16 с BOM.

Для чисел в Excel нажмите «Добавить числовую пару» и введите исходное число и подстановку. Дробные числа можно вводить с точкой или запятой, например `-125,50 → 807,25`. Кнопка «Заполнить из выделения» предложит случайное целое число для каждого уникального числового значения и текстовые коды для текстовых ячеек. Числовые пары сопоставляют значение ячейки целиком. Подстановки сохраняют числовой тип и формат ячеек, поэтому Excel использует их при пересчёте формул. При восстановлении укажите версию матрицы, которая использовалась при подмене. Если числовая подстановка уже есть в области и после подмены восстановление было бы неоднозначным, измените пару или уточните выделение.

Текстовые пары ищут буквальные фрагменты с учётом регистра, включая цифры в тексте. Для небольших значений, которые встречаются внутри других слов, проверьте предпросмотр. Файлы Excel могут содержать исходные данные в формулах, скрытых областях, свойствах и других элементах книги. Проверка находит известные текстовые и числовые значения из матрицы вне области, отмечает уже присутствующие подстановки и сообщает о признаках дополнительного содержимого. Перед передачей внешнему сервису проверьте файл целиком.

Открываются книги `.xlsx` до 20 МиБ и 300 000 ячеек с данными или оформлением. Поддерживаемые элементы включают обычные формулы, оформление ячеек и объединения. Книги с рисунками, диаграммами, сводными таблицами, защищёнными листами и рядом специальных расширений Excel отклоняются. Защита структуры книги сохраняется при обработке. Изменение форматированного внутри ячейки текста блокируется с указанием адреса. Формулы сохраняются, и Excel пересчитывает их при открытии. Содержимое файлов удаляется при закрытии, выходе, через час бездействия или после перезапуска приложения. История операций хранится 90 дней. Версии матриц доступны и после истечения этого срока.

## Резервное копирование

Храните дамп PostgreSQL и ключ матриц отдельно. Пароли базы можно сгенерировать заново при развёртывании на новом сервере. Без исходного ключа содержимое существующих версий матриц восстановить нельзя.

```bash
umask 077
docker compose exec -T db pg_dump -U postgres -d podmena -Fc > podmena.dump
```

Восстанавливайте в **новое пустое развёртывание**, в котором ещё не запускали миграции. Поместите исходный ключ матриц в `.secrets/matrix_key` и подготовьте пароли базы. Проверьте, что Compose-проект указывает на новый том PostgreSQL.

```bash
docker compose up -d --wait db
docker compose exec -T db pg_restore -U postgres -d podmena --exit-on-error < podmena.dump
docker compose exec -T db psql -U postgres -d podmena -v ON_ERROR_STOP=1 -c 'TRUNCATE login_sessions'
docker compose up -d --build --wait
```

После восстановления войдите в систему и проверьте восстановление текста по сохранённой версии матрицы.

## Проверки разработки

```bash
python3.12 -m pip install -r requirements.txt -r requirements-test.txt
python3.12 -m unittest discover -s tests -v
npm --prefix frontend ci
npm --prefix frontend run build
docker compose config --quiet
```

Автоматические тесты API по умолчанию используют временную SQLite. Для проверки на PostgreSQL установите `PODMENA_TEST_DATABASE_URL`, указывающий на отдельную **пустую тестовую** базу. Тесты создают таблицы для сценариев и удаляют их при завершении.
